# KwaiGrow Assistant 详细说明文档

## 1. 项目定位

**KwaiGrow Assistant（快手增长助手）** 是一个面向“内容互动运营”的流程自动化工具。  
它把“找内容、读内容、写评论、发评论、记记录”这一套动作工程化，降低手工重复操作成本。

---

## 2. 核心功能清单

### 2.1 关键词策略层

1. 输入方向词（如：找工作、面试技巧、职业成长）。
2. AI 扩展出更聚焦的检索词。
3. 自动跳过历史已使用关键词（避免每轮都搜同一个词）。

### 2.2 内容抓取层

1. 进入快手搜索页。
2. 抓取候选帖子列表（支持数量上限）。
3. 对每条候选读取摘要信息与热评摘要。

### 2.3 评论决策层

1. AI 判定是否适合评论（可严格或宽松）。
2. AI 生成多条评论候选。
3. 按规则过滤（长度、违禁词、重复文本）。
4. 在必要时启用兜底评论文案（可配置开关）。

### 2.4 执行与记录层

1. 自动填写评论输入框并发送。
2. 发送后进行确认，必要时重试。
3. 成功写入 SQLite 记录，作为后续去重依据。

### 2.5 控制台能力

- 顶部核心按钮：开始任务（单轮/持续）+ 停止任务。
- 设置面板折叠：AI配置与运行开关集中管理。
- AI 测试连接：可即时验证网关/模型/API Key。
- 实时状态：每秒轮询运行日志、统计、关键词历史、评论记录。

---

## 3. 典型用途场景

### 场景 A：新账号冷启动

- 目标：保持规律互动，建立基础活跃。
- 建议：低频率、低上限、严格违禁词规则。

### 场景 B：主题内容触达

- 目标：围绕某领域（如求职、学习）持续触达。
- 建议：使用方向词 + AI扩词，避免机械化重复评论。

### 场景 C：运营策略 AB 验证

- 目标：测试不同评论风格带来的互动反馈。
- 建议：每次只调整一组规则（长度、语气、是否严格判定）。

---

## 4. 运行流程（端到端）

1. `main.py` 启动，加载配置。
2. `orchestrator` 做 AI 健康检查。
3. 浏览器登录态检查，不满足则提示先登录。
4. 按方向词扩词并检索帖子。
5. 逐条获取帖子上下文 → AI判定 → AI生成候选。
6. 规则过滤并提交评论。
7. 成功后写入 `data/*.sqlite3`。
8. 达到每轮/每日上限后暂停或结束。

---

## 5. 关键配置建议

### 5.1 互动节奏

- `runtime.max_comments_per_round`：单轮上限。
- `runtime.daily_comment_limit`：单日上限。
- `runtime.action_wait_seconds`：每次评论后的随机等待。
- `runtime.round_wait_seconds`：轮次间等待。

### 5.2 检索策略

- `runtime.search_limit_per_keyword`：每词抓帖量。
- `runtime.single_keyword_search`：每方向每轮只搜1个词。
- `browser.search_each_post`：是否每条帖子都重新搜。

### 5.3 文案质量控制

- `comment_rules.requirements`：评论生成要求。
- `comment_rules.banned_words`：禁用词。
- `comment_rules.min_length/max_length`：长度控制。
- `ai.strict_comment_gate`：严格判定开关。

## 6. 数据与文件说明

- `logs/*.log`：任务与控制台日志。
- `data/dedup*.sqlite3`：评论记录与去重历史。
- `config/kuaishou.yaml.example`：开源示例配置。
- `config.realrun*.yaml`：本地私有运行配置（不要提交）。

## 7. 开源发布建议

1. 仓库名建议：`kwaigrow-assistant`。
2. 保留示例配置：`config/kuaishou.yaml.example`。
3. 在 README 明确“只提交示例，不提交真实配置”。
4. 打开仓库 Secret Scanning。
5. 发布前执行一次手工检查：
   - 是否包含真实 API Key
   - 是否包含本地数据库
   - 是否包含浏览器 profile 数据

---

## 8. 术语说明

- **方向词**：你定义的主题词（如“找工作”）。
- **扩词**：AI 基于方向词产生的检索词（如“面试技巧”）。
- **评论门控**：是否允许在“AI建议跳过”时继续评论。
- **去重**：防止重复评论同一帖/同链接/同标题哈希。

---

## 9. 注意事项

- 该工具用于运营效率提升，不是“无限制自动刷量器”。
- 请控制频率、避免重复模板、避免违规词。
- 建议先小规模测试并观察账号反馈，再逐步放量。
